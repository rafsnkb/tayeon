Neumorphism + Soft UI Evolution · 자홍 → 코랄

uupm.cc/demo/health-wellness에서 값을 직접 뽑아 옮겼다. 그 데모의 구조는 머티리얼 두 개를 역할로 나눠 쓰는 것이다 — 크롬은 뉴모피즘, 읽는 내용은 Soft UI.

  • neu: 배경과 같은 색 + 이중 그림자(8/8, -8/-8, blur 16). 상단바 버튼, 스프레드, 추천 질문, 사이드바 항목에 쓴다.
  • soft: 흰 면 + 단일 그림자(0 4px 20px), radius 24. 말풍선과 카드처럼 읽는 내용은 전부 여기 올린다.
  • 입력칸은 눌러 넣은 면(inset)이다. 담는 컨트롤은 들어가고, 누르는 컨트롤은 솟아오른다 — 뉴모피즘이 상태를 표현하는 방식이다.
  • 눌리면 실제로 들어간다. 버튼을 클릭해보면 그림자가 inset으로 뒤집힌다.
  • 액센트만 그림자 색이 다르다. 데모의 rgba(accent,.3) 0 4px 14px 자리에 코랄을 넣었다.
  • 카드 번호를 원형 게이지로 뒀다 — 데모의 75% 링 자리다.
뉴모피즘의 함정은 대비다. 카드가 배경과 같은 색이라 경계를 그림자만으로 만드는데, 그림자는 대비 계산에 잡히지 않는다. 그래서 읽는 내용을 neu 면에 올리면 글자는 통과해도 면 자체가 안 보인다. 데모가 읽는 카드에 흰 면(soft)을 쓰는 이유이고, 여기서도 그 구분을 지켰다 — 아래 수치의 “본문”이 soft 기준인 것도 그래서다.
