레이아웃 · UX 재설계 — 편의성 우선

50대 테스터가 어려워했다는 피드백에서 출발했다. 추측하지 않고 실제 화면을 브라우저로 재서 원인을 특정했다(localhost:3000/tarot, 390px). 라벨 없는 아이콘 버튼 5개, 44px 미만 컨트롤 5개, 10~12px 글자 3곳이 나왔다.

근거로 쓴 스킬 규칙: touch-target-size(44×44pt / 48×48dp), touch-spacing(최소 8px), no-precision-required, gesture-alternative, input-labels, empty-states, progressive-disclosure.

규칙 위에 더 얹은 것은 연령대 때문이다 — 아이콘 단독 금지(전부 글자를 붙였다), 상태를 배지가 아니라 문장으로("14회" 대신 "14회 남았어요"), 최소 글자 13px·본문 16px, 허공에 뜬 버튼 제거(전부 줄에 넣어 정렬을 맞췄다).

남은 판단: 상단바의 글자 라벨이 공간을 먹는다. 제목이 길면 잘린다 — 제목을 두 줄로 둘지, 라벨을 아이콘 아래 더 작게 둘지는 실제 대화 제목 길이를 보고 정하는 편이 낫다.
