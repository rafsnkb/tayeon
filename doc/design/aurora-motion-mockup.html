Aurora UI + Motion-Driven · 자홍 → 코랄

움직입니다. 정지 화면으로는 절반만 보입니다 — 배경이 9·11·13초 주기로 흐르고, 말풍선이 차례로 밀려 들어오고, 버튼은 눌리고 떠오릅니다. 커서를 버튼과 추천 질문 위에 올려보세요.

  • 유리를 걷어냈다. Aurora UI는 배경만 흐르고 콘텐츠는 불투명한 면에 얹힌다. 다크가 탁해 보이던 건 반투명 면 때문이었다.
  • 대비가 확정값이 된다. 면이 불투명하면 뒤에 무엇이 오든 수치가 변하지 않는다 — 글래스 시안에서 "오로라 평균 기준"이라고 단서를 달아야 했던 부분이 사라진다.
  • 오로라 3겹이 서로 다른 주기로 흐른다(패럴랙스). 같은 속도면 그림 한 장이 흔들리는 것처럼 보인다.
  • 리딩 대기를 점 세 개로 바꿨다. 지금은 "이전 대화를 불러오는 중..." 같은 문장인데, 상태는 움직임으로 알리는 편이 빠르다.
  • 진입 애니메이션은 90ms씩 밀린다. 한꺼번에 나타나면 순서가 안 읽힌다.
  • prefers-reduced-motion을 존중한다. OS에서 모션 줄이기를 켜면 전부 최종 상태로 고정된다 — 스펙의 필수 항목이다.
Aurora UI 스펙은 8~12초 루프, background-size:200%, saturate(1.2), 색 레이어로 깊이를 만들 것을 요구한다. Motion-Driven은 호버 300~400ms, 패럴랙스 3~5겹, GPU 가속, 그리고 모션 감소 존중을 요구한다. 위 화면은 그 항목들을 그대로 따른다.

비용: 애니메이션은 transform과 background-position만 건드리므로 레이아웃을 다시 계산하지 않는다. 글래스모피즘의 backdrop-filter와 달리 스크롤 중 면마다 뒤를 다시 흐릴 필요도 없다 — 움직이는 쪽이 오히려 가볍다.
